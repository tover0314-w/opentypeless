# Task Report: KBD-006 Keyboard toolbar container

## Result

DONE

## Scope

- Implemented: capability-free status/primary/overflow toolbar container; two bounded primary
  Placement slots; fixed mode, continuous-dictation and overflow controls; Undo retained only in
  overflow; 48dp targets; compact landscape labels; narrow-landscape measurement; selected-system-
  IME verification on Xiaomi 10 Ultra and the ARM64 emulator.
- Not implemented: Action definitions, user toolbar customization, candidate bar, Rime, Emoji,
  clipboard panel, haptics/theme work or signed release.

## Changes

- `android/app/src/main/java/com/opentypeless/android/keyboard/toolbar/KeyboardToolbarLayout.java`:
  closed `PRIMARY`/`OVERFLOW` placement container with at most two primary actions, one overflow
  anchor, stable slots, exact 48dp minimums, bounded IDs and accessibility-label checks.
- `android/app/src/main/java/com/opentypeless/android/ime/OpenTypelessImeService.java`: binds the
  existing status, mode, continuous dictation and More controls to the new container; landscape
  uses compact mode text; transient Undo no longer squeezes the fixed row and remains available in
  the existing More menu.
- app and Test Host AndroidTests: direct View order/size/narrow-width/fail-closed tests plus the
  actual selected IME accessibility-window check.
- `android/architecture-tests/keyboard_toolbar_contract.py` and hostile tests: source capability,
  exact slot, single-wiring, overflow and system-test gates; preflight now invokes the gate.
- `third_party/rime/resource-policy.v1.json`: four changed KBD-006 APK identities registered only
  after recursive scans reported zero real Xiaohè and zero forbidden Rime resources.

## Architecture

- contracts: the toolbar accepts only Android `View` objects carrying already-bounded callbacks;
  it has no editor, action protocol, persistence, native, network or reflection capability.
- state changes: in-memory placement IDs map to a closed `PRIMARY` or `OVERFLOW` value. A third
  primary action, duplicate/invalid ID, unlabeled/non-clickable action or second overflow anchor
  fails closed.
- migration: none.
- feature flag: none; the existing mutually exclusive Route-A Shell flag remains unchanged.

The service has one status flex slot, exactly two 64dp primary controls and one 48dp overflow
anchor. Low-frequency Undo is generated by the existing More menu only. No editor operation or
writer path was added.

## Security & privacy

- data sent/stored: none.
- permissions/components: none.
- threat considerations: arbitrary Action/Placement execution is not introduced. Toolbar source
  gates reject `InputConnection`, editor, network, storage, native and reflective capabilities.
  Every interactive View requires a nonblank content description and at least 48dp source/View
  dimensions.
