## Scope delivered in 0.3

- Android system partial results now replace one owned editor composition instead of appending or
  remaining in a status label. Cursor movement, app/field changes, stale revisions, cancellation,
  rejected `InputConnection` operations and late callbacks fail closed.
- The compact IME and management screens use light/dark theme tokens, dynamic color on Android 12+,
  a transcript surface, an explicit recording state, wrapping 48 dp controls and Android 15 system
  bar/cutout insets.
- System recognition requests latency-optimized formatting. Settings identify the configured
  Android recognition service when the platform exposes it and separately report system/default
  and on-device API availability. An unavailable on-device route does not silently fall back to
  the default online-capable service.
- DashScope Paraformer realtime is a distinct, true streaming backend. It sends bounded 40 ms,
  16 kHz PCM frames through an allowlisted WSS endpoint, accepts revisable punctuated hypotheses,
  limits the outgoing queue and total transcript, and has terminal start/final/cancel/error paths.
  Its credential is encrypted independently from batch STT and LLM credentials.
- OpenAI-compatible WAV transcription remains available and is explicitly described as batch, not
  realtime. Provider changes are never automatic.
- A pinned SenseVoice Small INT8 route is available as an explicit 228.45 MiB download on supported
  non-low-RAM 64-bit devices. Model weights are not embedded in the APK. The download resumes exact
  byte ranges after bounded network failures, survives settings-activity recreation, verifies
  pinned sizes and SHA-256 before atomic installation, and keeps audio on the device.
- API 26/33/35/36 device-test jobs are defined in CI. A Xiaomi-specific evidence collector and a
  local latency/CER summarizer are included under `android/tools`.

## Independent review findings

| Severity | Finding | Resolution |
| --- | --- | --- |
| Critical | A late partial or final could target an editor after the user moved to another field. | Existing editor epoch/package/field/fingerprint guard now understands only the composition mutations owned by the active voice session; all other movement cancels. |
| High | Partial text was visible only in the keyboard and did not provide Baidu-style in-editor revision. | Added monotonic `TranscriptUpdate` and replace-in-place `setComposingText`; final text replaces the owned composition once. |
| High | Bounding each provider event did not bound a long stream containing many sentences. | The assembler now limits the complete transcript to 20,000 code points and 512 completed sentences, preserving the previously accepted prefix on rejection. |
| High | A pasted WebSocket URL or HTTP redirect could expose a bearer token to a look-alike host. | Streaming accepts only WSS, the exact inference path, no credentials/query/fragment/port, and the documented DashScope host forms; both HTTP and HTTPS redirect following are disabled. |
| High | The Gradle Wrapper fixed a version but did not authenticate the downloaded distribution. | Added Gradle's published SHA-256 for the 8.11.1 binary distribution and verified the checked-in wrapper JAR against Gradle's official checksum reference. |
| High | Android build and emulator jobs used mutable major-version Action tags despite release workflows already pinning third-party code. | Every CI Action reference now uses the exact commit resolved from its stated tag; Dependabot remains the update path. |
| Medium | Android's offline and partial-result extras could be mistaken for guarantees. | Diagnostics describe them as provider capabilities/hints; explicit on-device creation fails closed when unavailable. |
| Medium | Android 15 edge-to-edge could place programmatic screens under system bars. | All management/recognizer screens apply idempotent system-bar and display-cutout insets. |
| Medium | A slow network could accumulate realtime PCM indefinitely. | Complete audio is never retained on the streaming path and the WebSocket outgoing queue is capped before capture continues. |
| Medium | A device evidence bundle could expose the ADB identifier and unrelated installed IME package names. | The collector stores only a SHA-256 device correlation value and OpenTypeless registration/enabled/default booleans; the selected speech-service identity remains because it is required to diagnose the configured route. |
| Medium | A legacy or damaged encrypted key could reach a transport header builder without passing the new settings-form validation. | Streaming rejects an empty key; both batch and streaming reject oversized credentials and all ISO control characters before constructing authorization headers. The save path applies the same single-line rule. |
| Medium | The in-app third-party screen named Apache-2.0 runtime dependencies but did not include an offline-readable copy of that license. | Bundled legal notices now include the complete Apache License 2.0 text used by OkHttp, Okio and the Kotlin standard library. |
| Medium | CI inherited repository-default token permissions while executing third-party build and emulator Actions. | The workflow now grants only read access to repository contents; no job receives write permission. |
| High | The optional 229 MiB model transfer was cancelled or became invisible when Settings was recreated, and a transient read timeout restarted the artifact. | Added exact HTTP Range retry with strict `Content-Range` validation and an application-scoped operation coordinator that rebinds progress after rotation without retaining an Activity. |

No transcript or API key is logged. Settings screenshots are blocked with `FLAG_SECURE`; the Xiaomi
collector deliberately excludes logcat, screenshots, transcripts, clipboard, accounts and data
from other apps.

## Xiaomi 15 physical protocol

Build or download the exact CI debug candidate, enable USB debugging, then run from the repository
root:

```bash
android/tools/collect-xiaomi15-acceptance.sh \
  --adb "$ANDROID_HOME/platform-tools/adb" \
  --serial '<exact adb serial>' \
  --apk android/app/build/outputs/apk/debug/app-debug.apk \
  --smoke
```

Complete `manual-results.tsv` in the generated evidence directory against XM-P0-01 through
XM-P0-19 in the [current P0 matrix](2026-08-11-xiaomi15-p0-acceptance.md). Record at least 20 fixed
short utterances for each shipping recognition route in a copy of
`android/tools/latency-template.csv`, then run:

```bash
android/tools/summarize-latency.py xiaomi15-latency.csv \
  --output xiaomi15-latency-summary.json
```

Attach the generated `.tar.gz`, completed manual table and aggregate latency summary to the draft
PR. Do not use personal messages or credentials as test material.

## Release decision

Voice Core 0.3 may be merged only after all GitHub checks pass and the review findings remain
resolved. It may be described as a live-composition, optional-offline, true-streaming voice-input
milestone.

Android IME 1.0 must **not** be declared complete from this candidate: the Fcitx5 Android + Rime
keyboard base, user-owned 小鹤音形 data migration, embedded toolbar integration, LGPL distribution
work and physical Xiaomi 15 XM-01 through XM-14 evidence are separate blocking gates. Emulator and
static results cannot waive them.
